# TI4 Faction Quick Reference

An unofficial fan reference for Twilight Imperium 4 factions: overview, units and special cards for all 30 factions (base game, Prophecy of Kings, Codex, Thunder's Edge).

**Live site:** https://tegidc.github.io/ti4-faction-reference/

- Search or scroll the faction row; hover or tap a faction to see it big.
- Switch between Overview, Units and Special cards.
- Strategy cards: all 8 cards, and on a game tab who picked which this round.
- Add an AsyncTI4 game by its code (e.g. `pbd14000`) to get a tab with just that game's factions, a leaderboard, and faded leaders that haven't been unlocked yet. The page checks AsyncTI4 for new moves every couple of minutes while it's open.

Twilight Imperium © Fantasy Flight Games. Card scans via ti4.basicallyfine.com; game data from the public AsyncTI4 API. Not affiliated with or endorsed by either.

## Rebuilding

`index.html` is generated: edit `template.html`, then run `python3 build/build.py` from this folder.
